Regresión lineal: conceptos básicos

La regresión lineal relaciona una variable dependiente (Y) con una o varias variables explicativas (X). Permite describir asociaciones y realizar predicciones. Primero repasamos el modelo con una sola X.

Predicción y residuo

En regresión simple, Ŷ = β̂₀ + β̂₁X. Los β̂ son coeficientes estimados y los β, parámetros poblacionales. El intercepto indica la predicción para X = 0 y la pendiente, el cambio esperado de Y por unidad de X. El residuo es eᵢ = Yᵢ − Ŷᵢ.

Mínimos cuadrados ordinarios (MCO): estima los coeficientes minimizando Σ(Yᵢ − Ŷᵢ)².
MCO minimiza las distancias verticales al cuadrado, no las perpendiculares a la recta. Puedes verlas en la pestaña 2.

De la regresión simple a la múltiple

El consumo eléctrico puede relacionarse con la temperatura exterior y con el número de electrodomésticos en uso. La regresión múltiple permite incorporar ambas variables.

Regresión simple
Ŷ = β̂₀ + β̂₁X₁
Una variable explicativa. En dos dimensiones representamos una recta.
Regresión múltiple
Ŷ = β̂₀ + β̂₁X₁ + β̂₂X₂
Dos variables explicativas. La predicción se representa mediante un plano.

En regresión múltiple, cada coeficiente se interpreta manteniendo constantes las demás variables explicativas.

Variables del ejemplo: Y = consumo eléctrico (kWh); X₁ = temperatura exterior (°C); X₂ = electrodomésticos en uso.
